Maclean

一键显示器休眠 · 清洁模式
极简 macOS 菜单栏工具，MIT 开源免费

下载 GitHub
🖥️

显示器休眠

一键只关闭显示器：不锁屏、不整机睡眠、不要求重新认证、不改系统设置。唤醒即恢复。

✨

清洁模式

全屏纯黑 + 屏蔽全部键盘输入，安心擦屏幕、擦键盘。悬停屏幕中央提示框 1.5 秒退出。

🔒

隐私优先

不记录键盘内容、不保存鼠标轨迹、无网络、无账号、无云端。日志只记状态与错误码。

从源码构建

git clone https://github.com/EathonEvans/maclean.git
cd maclean
make assets   # 生成图标资源
make build    # 编译
make test     # 单元测试
make package  # DMG + PKG 安装包

依赖：macOS 14+ · Xcode · xcodegen。清洁模式需要「辅助功能」权限。
